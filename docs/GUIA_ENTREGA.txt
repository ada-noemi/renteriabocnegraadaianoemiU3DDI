Actividad: APP Pantallas Inteligentes
Fecha de implementación: 25 de noviembre de 2026

1. Herramientas y configuración
Proyecto original Television / Empty Activity, conservando paquete com.example.relaxtv.
Kotlin y Compose; AndroidX TV Material; Media3 ExoPlayer y PlayerView.
Versiones del proyecto: AGP 9.4.1, Gradle 9.6.0, Kotlin Compose 2.2.10,
Compose BOM 2026.02.01, minSdk 26 y compile/targetSdk 37.
Media3 agregado: 1.11.1. Java disponible: Android Studio JBR 25.0.3.
Registrar en la entrega la versión de Android Studio desde Help > About.
El APK usa medios internos; no requiere Internet ni permisos de almacenamiento.
La primera sincronización/compilación necesita descargar dependencias.

2. Videos obligatorios antes de la prueba funcional
Videos locales actuales (conservados sin modificar):
app/src/main/assets/videos/lluvia.mp4
app/src/main/assets/videos/chimenea.mp4
app/src/main/assets/videos/oceano.mp4
Preferir video H.264, 720p o 1080p. La extensión MP4 no garantiza codecs compatibles.
Volver a compilar después de agregar o sustituir videos. Ya se incluyen los tres MP4 y los tres MP3 locales.
Si falta un video o falla su decodificación, aparece un error y se puede volver.
No hay reproducción simulada ni enlaces externos.

3. Emulador Android TV
En Android Studio abrir este mismo proyecto y sincronizar Gradle.
Tools > Device Manager > Create Virtual Device > TV > Android TV (1080p).
Elegir una imagen de Android TV API 26 o superior compatible con el equipo
(preferentemente API 35 o superior para pruebas). Descargar y finalizar el AVD.
Iniciar el AVD, seleccionarlo como destino y ejecutar el módulo app con Run.
Usar las flechas y OK del control remoto en Extended Controls, o teclado.
En el menú: izquierda/derecha seleccionan y Enter abre el ambiente.
En reproducción: OK/Enter pausa y reanuda; Back vuelve al menú.
Registrar nombre del AVD, API, arquitectura, resolución y configuración gráfica.
En esta sesión adb no mostró dispositivos y emulator -list-avds no mostró AVD.

4. Compilación y APK
Desde PowerShell en la raíz:
$env:JAVA_HOME = 'C:/Program Files/Android/Android Studio/jbr'
.\gradlew.bat :app:assembleDebug :app:lintDebug --console=plain
Tras BUILD SUCCESSFUL, APK de prueba:
app/build/outputs/apk/debug/app-debug.apk
Instalar con Run o adb install -r app/build/outputs/apk/debug/app-debug.apk
Para APK release firmado: Build > Generate Signed App Bundle or APK > APK.
Crear/seleccionar keystore, elegir release y conservar la clave fuera de GitHub.
El APK debug es suficiente para instalación y evaluación local si el profesor lo admite.
No confundir código fuente con APK; entregar ambos.

5. Organización para explicar el código
MainActivity.kt: pantalla activa, Back y conservación de selección.
Ambience.kt: catálogo de tres ambientes, imágenes y rutas locales.
HomeScreen.kt: tarjetas Compose, navegación por foco y resaltado.
PlayerScreen.kt: ExoPlayer, audio, bucle, errores, controles y ciclo de vida.
ui/theme/Theme.kt: tema oscuro.
AndroidManifest.xml: launcher TV, orientación horizontal, banner e icono.
res/drawable: ilustraciones vectoriales, icono y banner 320 x 180 con nombre.
El reproductor se crea en START y se libera en STOP o al salir de la pantalla.
Conserva posición y estado de pausa al regresar desde segundo plano.

ACTUALIZACIÓN: AUDIO AMBIENTAL INDEPENDIENTE
Se conservan los tres MP4 originales. Los MP3 encontrados en assets/audios/
se trasladaron a assets/audio/ para respetar las rutas solicitadas:
app/src/main/assets/audio/lluvia.mp3
app/src/main/assets/audio/chimenea.mp3
app/src/main/assets/audio/oceano.mp3
AmbientPlayback.kt controla dos ExoPlayer: uno de video silenciado y otro de audio.
Se preparan ambos antes de iniciar. Cada medio repite su propio bucle, aunque
sus duraciones difieran. OK/Enter pausa y reanuda los dos en su posición actual.
Back y ON_STOP liberan ambos. Al volver desde segundo plano se recuperan sus
posiciones independientes y el estado de pausa. Solo el audio solicita foco.
La falta o error de cualquiera de los medios impide continuar el ambiente.
Prueba manual adicional: comprobar sonido en los tres ambientes; pausar ambos,
esperar y reanudar; repetir varios bucles; volver al menú y comprobar silencio.
Verificación de la actualización de audio:
:app:assembleDebug y :app:lintDebug: BUILD SUCCESSFUL (build-audio-verified.log).
Se inspeccionó el APK: contiene los tres MP4 y tres MP3 en las rutas esperadas,
con tamaños iguales a los archivos locales. El APK actual incluye los medios.
No se ejecutó la reproducción en emulador: no hay AVD ni dispositivo conectado.
